# 木匣

自己人开的私人大富翁。棋盘是奶油色木盒的样子，规则按经典大富翁来。六个角色：柴猪 Shibagy、果熊 Ada、二柴 Erchai、小橘 Orangie、兔兔 Tutu、小金 Ginger。

不用注册。开一桌，把房号或链接发给同一网络里的朋友。每个人可以带一个或多个角色。

## 开始

```bash
npm install
npm run dev
```

浏览器打开 http://localhost:5173 。同一 Wi-Fi 的朋友用终端里打印的局域网地址。

## 内部密码

默认不需要密码。如果只想让家里人打开网页，编辑 `server/config.json`，把 `sitePassword` 填上，然后重启。这不是账号，只是一串共用的口令。

每个房间还可以再设一个房间密码。

## 断线

座位记在浏览器里。刷新或短暂断开会回到原座位。请让 `npm run dev` 一直开着；服务器重启后，半小时内的房间会从 `data/rooms.json` 恢复。清掉这个站点的本地数据后，就不能回到已经开始的那一局。
