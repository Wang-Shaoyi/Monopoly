# 棋盘图标资源

本目录保存中美两套棋盘的全部原图、题材、生成提示词和审阅材料。画风采用用户确认的第二轮简洁版：圆润轮廓、少量大色块、柔和配色，避免密集花纹和细碎建筑结构。

## 资源分工

- `originals/`：57 张内置 image_gen 生成的透明 PNG 原图（含保留的 Boston 备用素材）；包括复用的 5 张第二轮样稿。原图保留，不覆盖旧审阅版本。
- `../../client/src/assets/board-icons/`：网页使用的 256 × 256 透明 PNG。只对原图等比例缩小，不改画面内容。
- `production-manifest.json`：每张图标的语言、棋盘位置、题材和完整提示词。
- `gallery.html`：全部图标的浏览和下载页面。
- `contact-sheet.png`：最初 56 张图标的总览；新增华盛顿特区图标见 gallery.html。
- `research.txt`：中美题材的搜索记录。第一批题材来源还见 `review-v1/README.md`。
- `review-v1/`、`review-v2/`：保留之前两轮样稿与对照页。

## 接入规则

中英文各有 22 个城市图标。城市与交通图标约一半压在格子外边线上，左右两侧分别旋转 90°，使图标底部朝向棋盘中心；上、下两排保留原方向。中文的四个火车站共用高铁图标，英文的四个机场共用机场图标。10 个功能图标中英共用，摆在格子内部并始终保持正向，包括起点、机会、公益金、两种税、监狱、前往监狱、免费停车、电力、水务。所有图标的显示尺寸为初次接入时的 1.5 倍，原图资源不变。

映射位于 `client/src/boardIcons.ts`，展示位于 `client/src/Board.tsx` 与 `client/src/styles.css`。图片是装饰元素，不接收点击、不重复朗读地名，棋子显示在图片上层。英文地名采用聊天中最后确认的得州、佛罗里达、阿拉斯加、内华达、夏威夷、华盛顿、加州与华盛顿特区／纽约方案（Boston 图标和原图保留备用），卡牌目的地同时同步。

## 重新准备网页资源

从项目根目录运行：

```powershell
./art/board-icons/prepare-assets.ps1
./art/board-icons/make-contact-sheet.ps1
```

第一条命令会检查全部原图是否齐全，并保持透明通道生成网页资源。生成过程中可使用 `-AvailableOnly` 暂时准备已完成的图片。

本轮只接入美术和地名文案；棋盘位置、售价、租金、卡牌效果与游戏规则不变。
